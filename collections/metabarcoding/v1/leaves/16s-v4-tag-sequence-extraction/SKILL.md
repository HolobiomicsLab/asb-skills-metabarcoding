# 16s-v4-tag-sequence-extraction

## Summary

Extract the set of unique 90-bp V4 16S rRNA tag sequences (starting after primer 515f) from a Deblur exact-sequence BIOM observation table, so they can serve as query sequences for exact-sequence comparisons such as VSEARCH global alignment at 100% identity against reference databases like Greengenes and SILVA.

## When to use

Use when starting from a Deblur-generated feature/observation table (e.g., the EMP 90-bp V4 tag table) and you need the deduplicated set of exact amplicon sequences as FASTA queries for reference-database recapture or exact-match analyses.

## When NOT to use

- Input is an OTU-clustered table or closed-reference picking result against Greengenes 13.8/Silva 123 rather than a Deblur exact-sequence table — feature IDs would not be the sequences themselves.
- Amplicon region is not the V4 90-bp tag starting after primer 515f (e.g., ITS or 18S data from EMP500), since the tag length and primer context would differ.
- You need reference database construction or taxonomy assignment rather than extracting query sequences from an existing Deblur table.

## Inputs

- Deblur 90-bp V4 observation/BIOM table whose feature IDs are the exact tag sequences (e.g., from EMP 16S Release 1, ~25,000 samples across 97 studies)
- EMP study mapping files / merged metadata (optional, for restricting the sequence set to a sample subset)

## Outputs

- FASTA file of unique 90-bp V4 tag sequences extracted from the BIOM feature IDs
- Count/list of unique tag sequences available as VSEARCH query input (feeds reference_recapture_fractions.csv downstream)

## How to apply

Load the complete Deblur 90-bp observation table (BIOM format) and extract the feature IDs, which are the exact V4 tag sequences generated by the Deblur exact-sequence de novo OTU picking method (tag sequences are 90-bp 16S rRNA gene sequences starting after primer 515f). Dereplicate these feature IDs to obtain the unique tag sequence set, honoring filters used in the EMP release such as mc2 (minimum sequence count in an OTU to be included equals 2). Write the unique sequences to FASTA so they can be used as VSEARCH --usearch_global queries with --id 1.0 against full-length Greengenes 13.8 or non-eukaryotic SILVA 128 references. The rationale is that Deblur preserves exact sequence identity rather than clustering, so feature IDs are themselves the sequences and can be matched at 100% similarity to measure what fraction of reference diversity (e.g., 46% of Greengenes, 45% of SILVA in the EMP analysis) is recaptured by environmental surveys.

## Related tools

- **Deblur** (Exact-sequence de novo OTU picking method that produced the 90-bp V4 tag sequences; its BIOM feature IDs are the sequences to extract) — https://github.com/cuttlefishh/deblur
- **Python** (Scripted loading of the BIOM observation table and extraction of unique tag sequences (BIOM/Pandas)) — https://github.com/biocore/emp
- **redbiom** (Command-line query of the Qiita database to retrieve EMP sample data/contexts containing the Deblur tag features) — https://github.com/biocore/redbiom

## Examples

```
python -c "import biom; t=biom.load_table('emp_deblur_90bp.biom'); seqs=sorted(t.ids(axis='observation')); open('tags.fa','w').write(''.join('>%s\n%s\n'%(s,s) for s in seqs))"
```

## Evaluation signals

- All extracted sequences are exactly 90 nt, start after primer 515f, and are unambiguous nucleotide strings.
- The extracted set contains no duplicate sequences (unique count equals FASTA record count).
- Extracted feature IDs round-trip: every FASTA sequence is present as a feature ID in the source BIOM table.
- Sequences failing any applied filter (e.g., mc2 minimum count of 2) are excluded consistently with the EMP release criteria.
- Downstream VSEARCH --usearch_global --id 1.0 runs against Greengenes 13.8 and SILVA 128 reproduce the published recapture fractions (~46% and ~45% of references hit; ~10% and ~13% of tag sequences matching).

## Limitations

- Tag sequences cover only the 90-bp V4 region starting after primer 515f, so exact 100% matches to full-length reference sequences are limited to that region and cannot validate full-length identity.
- The extraction is only as complete as the Deblur observation table loaded; sequence count filters (e.g., mc2) and rarefaction choices (e.g., rarefying to 5,000 observations per sample in some analyses) change which sequences are available.
- SILVA comparisons must be subset to non-eukaryotic (bacterial and archaeal) taxa, otherwise fractions are not comparable to the published EMP values.
