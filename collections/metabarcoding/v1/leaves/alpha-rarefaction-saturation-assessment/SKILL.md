# alpha-rarefaction-saturation-assessment

## Summary

Verify within-sample alpha diversity differences and sequencing-depth saturation by parsing QIIME 2 rarefaction and group-significance visualizations (alpha_rarefaction.qzv, observed_features_group_significance.qzv) and identifying the depth at which observed-features curves plateau (~350 sequences/sample in the Lake Erie Tourmaline test dataset).

## When to use

Use when a .qzv rarefaction visualization and per-sample observed-features values are available and you must confirm a richness difference between metadata strata (e.g. 5.0-μm vs 0.22-μm size fractions) and the sampling depth where curves saturate.

## When NOT to use

- Input is a feature table without the .qzv diversity visualizations — alpha_rarefaction.qzv must first be generated by the Tourmaline/QIIME 2 diversity step.
- The rarefaction config used a core_sampling_depth/alpha_max_depth other than 500, so the expected ~350 sequences/sample plateau depth is not comparable.
- Beta diversity or compositional dissimilarity questions — this skill only assesses within-sample richness (observed features), not between-sample ordination.

## Inputs

- alpha_rarefaction.qzv (QIIME 2 rarefaction visualization, observed-features metric, plot_diversity: true, alpha_max_depth 500)
- observed_features_group_significance.qzv (QIIME 2 group significance visualization from the unfiltered run)
- sample_metadata_file (TSV, e.g. 00-data/metadata.tsv) with size-fraction annotations (5.0-um, 0.22-um)

## Outputs

- alpha_diversity_verification.tsv with group medians, direction of difference, plateau depth, and pass/fail flags
- Identified rarefaction plateau depth (expected ~350 sequences/sample)
- Group stratification of per-sample observed-features values by size fraction

## How to apply

Parse observed_features_group_significance.qzv from the unfiltered Tourmaline diversity run with the QIIME 2 Artifact API / pandas to extract per-sample observed features, then join with sample_metadata_file (e.g. 00-data/metadata.tsv) to stratify by size fraction and compare richness between the 5.0-um and 0.22-um groups. Separately parse alpha_rarefaction.qzv — generated with plot_diversity: true using alpha_max_depth 500 and core_sampling_depth 500 in the Tourmaline config — to extract observed-features rarefaction curves. Identify the depth at which the curves plateau, checking against the expected ~350 sequences per sample. Write a compact summary table (group medians, direction of difference, plateau depth, pass/fail flags) to alpha_diversity_verification.tsv.

## Examples

```
qiime diversity alpha-rarefaction --i-table table.qza --p-metrics observed_features --p-max-depth 500 --m-metadata-file 00-data/metadata.tsv --o-visualization alpha_rarefaction.qzv
```

## Evaluation signals

- 5.0-um fraction shows higher observed features than the 0.22-um fraction across the group-significance results (pass condition).
- Rarefaction curves level off by approximately 350 sequences per sample (pass condition).
- alpha_diversity_verification.tsv is written with the required columns: group medians, direction of difference, plateau depth, pass/fail flags.
- Rarefaction curves were generated with plot_diversity: true, alpha_max_depth 500, and core_sampling_depth 500, so extracted depth range spans up to 500.

## Limitations

- Plateau depth (~350) is dataset-specific and calibrated against the Lake Erie 16S rRNA amplicon test dataset; it may differ for other amplicon data.
- Assessment depends on the rarefaction depth ceiling in the config (500); deeper saturation beyond 500 cannot be detected.
- Results reflect the unfiltered run; applying representative-sequence filters (taxonomy, length, abundance, prevalence, ID) changes observed-features values.
