# hill-numbers-alpha-diversity-estimation

## Summary

Compute Hill Numbers (order 0 = observed richness, 1 = Shannon's Entropy, 2 = Simpson's Index) per bat guano sample from rarefied COI feature tables using Phyloseq/Vegan in R, then test whether denoising program (DADA2, Deblur, VSEARCH) and filtering regime significantly alter these alpha diversity estimates.

## When to use

Use when comparing per-sample alpha diversity across metabarcoding feature tables generated by different denoising or clustering pipelines, or when quantifying how stringency of sequence filtering changes diversity estimates.

## When NOT to use

- Input is already a single-denominator beta diversity or ordination result — this skill is specifically about per-sample alpha estimates on rarefied tables
- Samples cannot be rarefied to the 5,000-read depth because they fall below the standard filter's ≥5,000 total filtered reads threshold
- The question is taxonomic classifier accuracy rather than diversity metric sensitivity — use the classifier benchmarking workflows of this study instead

## Inputs

- QIIME 2 feature tables (qza) of bat guano COI amplicon data from SRA PRJNA518082, one per denoising pipeline (DADA2, Deblur, VSEARCH) and per filtering regime
- Raw paired-end reads imported into QIIME 2 v2018.11 and adapter-trimmed with Cutadapt (minimum length 175 bp)
- Host/mock COI contamination labels used to define the 'miss' mock subtraction integer for the extra filter

## Outputs

- Per-sample Hill Number 0 (observed richness), Hill Number 1 (Shannon's Entropy), and Hill Number 2 (Simpson's Index) values at 5,000 reads/sample
- Kruskal–Wallis test statistics with Dunn's post hoc pairwise comparisons among DADA2, Deblur, and VSEARCH per filtering regime
- Figures 3 / S2-style plots of per-sample richness and diversity by denoising program and filtering regime

## How to apply

After denoising or clustering the COI paired-end reads and removing host/mock COI sequences, apply one of three filtering regimes — basic (no additional filtering), standard (drop sequence variants observed in only one sample and retain samples with ≥5,000 total filtered reads), or extra (standard plus subtraction of a per-library fixed integer defined as the maximum count of a 'miss' mock sequence variant). Rarefy each filtered feature table to 5,000 reads per sample, then compute Hill Numbers 0, 1, and 2 for every guano sample with Phyloseq/Vegan in R. Because Hill orders 0, 1, and 2 weight rare taxa progressively less, this trio reveals whether abundance weighting (RA vs PA transformations) changes the diversity picture. Test group differences among DADA2, Deblur, and VSEARCH samples with a Kruskal–Wallis test per filtering regime and Hill number, followed by Dunn's post hoc pairwise tests in R (Tidyverse, Phyloseq, Vegan), and plot per-sample estimates to reproduce the Figure 3 / Figure S2 pattern.

## Related tools

- **QIIME 2** (imports raw paired-end guano reads, runs Cutadapt trimming, DADA2 and Deblur denoising, and exports feature tables filtered per regime before rarefaction) — https://github.com/devonorourke/tidybug
- **DADA2** (default error-model denoising pipeline producing one of the three feature tables compared)
- **Deblur** (denoising run with non-default parameters '--p-min-reads 2' and '--p-min-size 1' so only singleton reads are discarded)
- **VSEARCH** (OTU clustering pipeline (merge, dereplicate, 98% identity clustering, de novo chimera filtering, final 97% clustering) producing the third feature table) — https://github.com/torognes/vsearch
- **Phyloseq** (computes Hill Numbers 0, 1, 2 from the rarefied feature table in R)
- **Vegan** (supports alpha diversity estimation and the statistical comparisons alongside Phyloseq)
- **Tidyverse** (R data handling, Kruskal–Wallis/Dunn's test orchestration, and plotting of Figures 3 / S2 patterns)

## Examples

```
Rscript -e 'library(phyloseq); ps_rare <- rarefy_even_depth(ps, sample.size=5000); hill <- estimate_richness(ps_rare, measures=c("Observed","Shannon","Simpson"))'
```

## Evaluation signals

- Kruskal–Wallis tests identify significant differences in Hill-number alpha diversity among DADA2, Deblur, and VSEARCH samples across filtering regimes
- With the exception of Hill Number 0 for basic-filtered data, all other diversity estimates differ significantly among filtering and denoising groups
- VSEARCH-processed samples repeatedly show 2–3x more ASVs per sample than DADA2 or Deblur
- Per-sample plot pattern matches Figures 3 and S2 of the paper (alpha diversity remains sensitive to denoising platform after filtering)
- All samples retained after standard filtering contain ≥5,000 total filtered reads and are rarefied to exactly 5,000 reads per sample before computing Hill numbers

## Limitations

- Hill Number 0 on basic-filtered data does not differ significantly among pipelines, so richness-only conclusions can flip depending on filtering stringency
- Alpha diversity estimates are highly sensitive to the denoising program choice, so single-pipeline diversity values should not be treated as ground truth
- The 'extra' filter subtraction uses a fixed integer derived from mock community 'miss' variants, which is experiment-specific and may not transfer to other datasets
- Rarefaction to a fixed 5,000-read depth discards abundance information above that depth and constrains which samples are comparable
