# wang-bayesian-classifier-confidence-threshold-sweep

## Summary

Sweep the mothur classify.seqs Wang Bayesian classifier confidence cutoff (30–98) to quantify how often in-silico 16S amplicons fail species-level classification against Greengenes, as used to show the V4 region has a 56% species-level failure rate while full-length V1–V9 nearly recovers source-species identity.

## When to use

Use when you need to quantify species-level classification failure of short 16S sub-region amplicons (especially V4) versus full-length V1–V9 by sweeping classifier confidence cutoffs against a reference taxonomy.

## When NOT to use

- When the goal is strain- or SNP-level resolution of intragenomic 16S copies — the paper treats that with full-length long-read sequencing and phasing of 16S gene SNPs, not classifier cutoff sweeps
- When input data are real amplicon reads (e.g., FASTQ from mock or in-vivo communities) rather than in-silico amplicons with known source species, since the failure-rate computation depends on known ground-truth source species

## Inputs

- In-silico 16S amplicon FASTA sequences (sub-region and full-length V1–V9, derived from reference genomes)
- Greengenes reference alignment (FASTA-formatted reference sequences)
- Greengenes taxonomy file (lineage strings for reference sequences)

## Outputs

- Per-region species-level failure-rate table: fig1b_species_failure_rates.csv (fraction of amplicons failing to confidently match their source species, per sub-region and full-length)
- Taxonomy assignments per amplicon at each confidence cutoff in the 30–98 sweep

## How to apply

Load the in-silico amplicon FASTA sequences (generated by excising sub-regions such as V4 from reference genomes) together with the Greengenes reference alignment and taxonomy files. Run mothur classify.seqs with the Wang Bayesian classifier against the Greengenes reference, sweeping the cutoff parameter from 30 to 98 to obtain taxonomy assignments at each threshold. Extract the species-level label from each assignment and compare it to the known source species of the reference genome from which each amplicon was derived. Compute the per-region species-level failure rate — the fraction of amplicons whose species assignment differs from, or fails to confidently reach, the source species — for each 16S sub-region and for the full-length V1–V9 amplicon. Validate by comparing computed failure rates against the reported values (V4 worst at 56% failure; near-complete recovery for full-length V1–V9) and write the per-region table to fig1b_species_failure_rates.csv. The rationale is that short variable regions cannot recapture the diversity of the full ~1500 bp gene, so the cutoff sweep exposes how classification confidence inflates apparent species-level resolution.

## Examples

```
mothur "#classify.seqs(fasta=amplicons.fasta, reference=gg_13_8.fasta, taxonomy=gg_13_8.tax, cutoff=80)"  # repeat with cutoff=30..98
```

## Evaluation signals

- Reproduced V4 species-level failure rate of 56% of amplicons failing to confidently match the sequence from which they were derived (Fig. 1b value)
- Full-length V1–V9 amplicons show near-complete recovery of the source species assignment relative to sub-regions
- Cutoff sweep covers the full 30–98 range, producing taxonomy assignments at each threshold
- Output table fig1b_species_failure_rates.csv contains one failure-rate value per 16S sub-region plus full-length V1–V9, each computed as the fraction of amplicons whose species label differs from or fails to reach the source species

## Limitations

- Short-read sequencing of 16S variable regions cannot achieve the taxonomic resolution of sequencing the entire (~1500 bp) gene; none of the variable regions recaptured the diversity represented by the full gene
- Results are specific to the Greengenes reference database and the Wang classifier cutoff behavior; other references/classifiers may shift thresholds and failure rates
- Confidence-cutoff sweeps measure label agreement, not biological ground truth for novel taxa absent from the reference
