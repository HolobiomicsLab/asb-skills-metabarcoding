# habitat-specific-naive-bayes-classification

## Summary

Improves species-level taxonomic classification of amplicon sequences by training q2-feature-classifier naive Bayes classifiers with habitat-specific (bespoke) taxonomic weights assembled from Qiita/EMP distributions via q2-clawback, instead of assuming uniform reference species priors.

## When to use

Use when classifying 16S/marker-gene sequences with q2-feature-classifier and species-level resolution matters, and the query sample's EMPO 3 habitat is known or can be matched to characterized Qiita samples for weight assembly.

## When NOT to use

- The query sample's environment lacks sufficient characterization for bespoke weight assembly (e.g., rare natural sample types) — average weights estimated from global microbial species distributions are then superior to uniform weights, but fully bespoke weights from that habitat cannot be assembled
- The sample distribution is highly unusual (e.g., synthetic populations) unless you first compile custom bespoke weights from existing similar samples
- Genus-level accuracy is sufficient — the benefit of bespoke weighting is concentrated at species level, and performance can degrade for rare species under bespoke weighting

## Inputs

- Marker-gene reference sequence database with full-rank taxonomy (e.g., Greengenes, RefSeq, SILVA 138.1)
- Environment-matched sample data / feature tables from Qiita for the target EMPO 3 habitat (retrieved via redbiom)
- EMPO 3 habitat label for the query samples (e.g., animal-distal-gut, soil-non-saline, human-stool)
- Precomputed class weights from the readytowear repository, or bespoke weights generated by q2-clawback (Artifact Class: FeatureData[Taxonomy] weights / .qza)

## Outputs

- Trained q2-feature-classifier naive Bayes classifiers (uniform-weighted and bespoke-weighted)
- Species-level taxonomic classifications for query sequence variants
- Per-phylum/per-habitat species-level error-rate comparisons (e.g., supplementary_fig5_error_rates.csv) with paired t-test P-values

## How to apply

Naive Bayes classifiers assume all reference species are equally likely to be observed; because this assumption is always violated, accuracy degrades linearly, so replace it with an empirical taxonomic distribution for the sample's source environment. First fetch environment-matched Qiita samples for the relevant EMPO 3 habitat using q2-clawback's fetch_Qiita_samples (redbiom-backed sample discovery), then generate habitat-specific class weights with generate_class_weights — or skip clawback entirely by loading precomputed weights from the readytowear repository. Train the q2-feature-classifier naive Bayes classifier on the reference database (e.g., Greengenes or SILVA 138.1) twice: once with uniform species weights and once with the bespoke weights. Classify test sequence variants per habitat under both schemes and compare species-level error rates, since bespoke weighting is expected to beat uniform (e.g., Proteobacteria 35.4%→22.3%, Firmicutes 43.6%→24.3% averaged over 14 EMPO 3 habitats, paired t-tests P ≈ 1.4e-6 and 8.4e-6). The more specific the weights are to the query sample's environment, the better the expected accuracy — even deliberately incorrect cross-habitat weights outperformed uniform in the majority of cases.

## Evaluation signals

- Bespoke weighting drops Proteobacteria species-level error from ~35.4% (±0.7% s.e.) to ~22.3% (±0.4% s.e.) with paired t-test P ≈ 1.4e-6 across 14 EMPO 3 habitats
- Bespoke weighting drops Firmicutes species-level error from ~43.6% (±0.7% s.e.) to ~24.3% (±0.3% s.e.) with P ≈ 8.4e-6
- Overall average species-level error rate declines from ~25% (uniform) to ~14% (bespoke), comparable to existing classifiers' genus-level error rate of 16%
- Bespoke-weighted classifier outperforms the uniform-weighted classifier per habitat; cross-habitat (incorrect) weights should still beat uniform in the majority of habitats
- Assembled weights match precomputed readytowear weights for the same primer/database/habitat combination

## Limitations

- Performance degradation was observed for rare species under bespoke weighting
- Bespoke classification is not immune to errors from poorly curated reference data (e.g., reference sequence misannotation), and empirical species distributions can propagate misannotated sample types or sequencing biases into the weights
- Systematic errors from bias in common sequencing techniques are not controlled without integrating multiple technologies for microbial distribution estimation
- Accurate classification requires matching the query sample's source environment to a well-characterized habitat; natural sample types lacking sufficient characterization cannot have bespoke weights assembled
