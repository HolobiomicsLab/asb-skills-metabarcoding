# alpha-diversity-index-interpretation

## Summary

Extract, tabulate and interpret per-sample alpha-diversity (Simpson index) values from 16S/ITS metabarcoding data, linking them to Bray-Curtis beta-diversity ordering and Mantel-test geography signals. In the trout-farm study this produced six Simpson values (N-I 0.86, N-P 0.49, B-I 0.64, B-P 0.54, G-I 0.79, G-P 0.66) for inflow (I) vs pond (P) water at farms N, B and G.

## When to use

Use when metabarcoded community samples (e.g. 16S V3-V4 / ITS2 amplicons) must be summarized by a per-sample alpha-diversity metric such as Simpson, and the values must be interpreted against water source, location, and beta-diversity patterns.

## When NOT to use

- Input is already a diversity summary or the goal is taxonomic composition (e.g. Proteobacteria ~75.57%, Bacteroidetes ~14.4%) rather than per-sample alpha-diversity quantification
- You need beta-diversity for eukaryotic/ITS OTUs — the article's Bray-Curtis ordering was computed for prokaryotes only
- Samples lack a reproducible location/water-source design, since interpretation (inflow vs pond, farm location effects) depends on that two-factor structure

## Inputs

- Paired-end 16S V3-V4 and ITS2 FASTQ reads from inflow- and pond-water samples (500 ml sterile bottles, 5 cm below surface, triplicates bulked)
- Quality-filtered and clustered OTU count table (SILVAngs output; OTUs clustered with cd-hit-est v3.1.2)
- Sample metadata mapping samples to location codes (N, B, G) and water source (I, P)

## Outputs

- Simpson diversity index value per sample (six values: 0.86 N-I, 0.49 N-P, 0.64 B-I, 0.54 B-P, 0.79 G-I, 0.66 G-P)
- Bray-Curtis beta-diversity ordering for prokaryotes (G-I highest, B-P lowest)
- CSV diversity table with columns location_code, water_source, simpson_index, beta_diversity_rank (6 data rows)

## How to apply

From the processed OTU/ASV data (here generated by the SILVAngs pipeline from paired-end FASTQ merged with BBmerge and trimmed with BBduk at Q30), calculate alpha-diversity according to the Simpson diversity index, one value per sample. Label each value by location code and water source (I = inflow, P = pond) so the six farm-site combinations (N-I, N-P, B-I, B-P, G-I, G-P) are unambiguous; each Simpson value must lie between 0 and 1, where higher values indicate greater community diversity. Interpret alpha values jointly with beta-diversity: Bray-Curtis dissimilarity was computed for prokaryotes only, with G-I highest and B-P lowest, and the Mantel test (IBD v1.52 and XLSTAT 2017) showed no significant correlation for the I-source samples, supporting the finding that pond-water biodiversity is more related to location than to water source. Assemble the results as a table with location code, water source, simpson_index, and beta_diversity_rank, one row per site-source combination.

## Related tools

- **SILVAngs** (Online automatic SILVA-based pipeline used for data analysis of compressed FASTQ files, from which the Simpson diversity index was calculated)
- **cd-hit-est v3.1.2** (Clusters dereplicated reads into OTUs at identity criteria 1.00 and 0.98, providing the OTU abundance input for diversity calculation)
- **IBD v1.52** (Used with XLSTAT 2017 for the isolation-by-distance Mantel test that contextualizes diversity patterns against geographic distance)
- **XLSTAT 2017 (Addinsoft, Paris, France)** (Software used to perform the Mantel test correlating geographic distance with beta-diversity, supporting interpretation of alpha-diversity patterns)

## Evaluation signals

- Exactly 6 data rows are produced, one per farm-location x water-source combination (N-I, N-P, B-I, B-P, G-I, G-P)
- Every simpson_index value matches the reported references (0.86, 0.49, 0.64, 0.54, 0.79, 0.66) and lies between 0 and 1
- In the beta_diversity_rank column, G-I is ranked highest and B-P lowest (Bray-Curtis, prokaryotes only)
- The required fields (location code, water source, simpson_index, beta_diversity_rank) are present in diversity_index_table.csv
- Interpretation is consistent with the Mantel result: no significant correlation observed for the I-source samples, and pond-water biodiversity more related to location than water source

## Limitations

- Exact farm locations cannot be disclosed (withheld at farmers' request), limiting geographic reproducibility of location-based diversity comparisons
- Some OTUs remained unclassified or unassigned where (% sequence identity + % alignment coverage)/2 did not exceed 93, which can understate diversity
- Beta-diversity (Bray-Curtis) was computed for prokaryotes only, so beta comparisons cannot be extended to the eukaryotic/ITS data
- No significant Mantel correlation for the I-source samples means inflow-sample diversity patterns cannot be attributed to geographic distance in this dataset
