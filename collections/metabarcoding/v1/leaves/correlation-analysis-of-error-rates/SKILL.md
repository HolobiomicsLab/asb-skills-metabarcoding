# correlation-analysis-of-error-rates

## Summary

Quantifies how much of the species-level classification error rate of bespoke (clawback) taxonomic weights is explained by the confusion index — the log expected taxonomic distance between closely similar (k-mer Bray-Curtis < 0.25) sequences from different species in the same habitat — by fitting a linear regression of per-habitat error rate on confusion index.

## When to use

Use when you have per-habitat bespoke-weight species-level error rates and per-habitat weighted reference distributions, and want to test whether the confusion index predicts those error rates (target: Pearson r2 = 0.72, P = 1.4e-4).

## When NOT to use

- You are still generating or selecting taxonomic weights (use q2-clawback/readytowear weights directly) rather than explaining the error rates of weights you already have
- Input is raw per-sample or per-sequence classification output instead of aggregated per-habitat error rates — you must first aggregate species-level errors per habitat before fitting the correlation
- The sample habitats lack sufficiently characterized bespoke weights (e.g., natural sample types with insufficient Qiita/EMP characterization), so no per-habitat error rates or weighted distributions exist to correlate

## Inputs

- Per-habitat bespoke taxonomic weights generated by q2-clawback generate_class_weights (weighted reference distributions over Greengenes taxa)
- Per-habitat species-level classification error rates on held-out test samples (from q2-feature-classifier classifications)
- Greengenes taxonomy (used to compute taxonomic distance between confused sequences)

## Outputs

- confusion_index_vs_error.csv containing per-habitat confusion indices, per-habitat error rates, and correlation statistics (Pearson r2, P-value)
- Fitted linear regression of species-level error rate on confusion index (Fig. 5 analogue)

## How to apply

Load the per-habitat bespoke taxonomic weights generated with q2-clawback's generate_class_weights for the evaluated environments (or the readytowear equivalents). For each habitat, sample 10^8 pairs of sequences from that habitat's weighted reference distribution and retain only pairs whose k-mer Bray-Curtis dissimilarity is < 0.25. For each retained pair, compute the expected taxonomic distance using the Greengenes taxonomy, and take the log of that expectation as the habitat's confusion index. Join the per-habitat confusion indices with the per-habitat species-level error rates measured on held-out test samples, fit a linear regression of error rate on confusion index, and report the Pearson r2 and P-value (the paper reports r2 = 0.72, P = 1.4 × 10−4 for Fig. 5). The rationale is the paper's finding that classification accuracy degrades linearly with the degree to which the uniform-species-abundance assumption is violated, so the confusion index — a measure of within-habitat taxonomic ambiguity — should linearly explain bespoke-weight error rates.

## Examples

```
from scipy.stats import pearsonr; r2, p = pearsonr(per_habitat['confusion_index'], per_habitat['error_rate']); assert abs(r2**2 - 0.72) < 0.1
```

## Evaluation signals

- Reproduced Pearson correlation between confusion index and per-habitat bespoke species-level error rate approximates r2 = 0.72 with P = 1.4e-4 as reported for Fig. 5
- Retained sequence pairs are strictly those with k-mer Bray-Curtis dissimilarity < 0.25; pairs at or above this cutoff must be excluded before computing expected taxonomic distance
- Exactly 10^8 pairs sampled per habitat from that habitat's weighted reference distribution; per-habitat sampling must not mix habitats
- confusion_index_vs_error.csv contains one row per habitat with non-null confusion index, non-null error rate, and finite regression statistics
- Confusion index values are log-transformed expected taxonomic distances computed against the Greengenes taxonomy (positive values expected for real confusions)

## Limitations

- The correlation explains bespoke-weight accuracy only insofar as it is driven by within-habitat confusion of similar sequences; it does not account for errors from poorly curated reference data such as reference sequence misannotation
- Empirical species distributions used to build weights carry their own error sources (misannotation of sample types, sequencing biases) which propagate into the error rates being explained
- Degradation in performance for rare species was observed under bespoke weighting, so the linear error-vs-confusion relationship may be less reliable for rare species
