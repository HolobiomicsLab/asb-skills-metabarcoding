# greengenes-reference-database-matching

## Summary

Classify 16S rRNA amplicon sequences (full-length V1-V9 or sub-regions such as V4) against the Greengenes reference database with a Wang Bayesian classifier in mothur, sweeping the confidence cutoff to quantify how often in-silico or real amplicons recover species-level taxonomy.

## When to use

Use when you have FASTA amplicon sequences (e.g., in-silico 16S sub-region or full-length amplicons) with a Greengenes reference alignment and taxonomy file and need to measure species-level classification accuracy or failure rates.

## When NOT to use

- Input is already a classified feature table or OTU abundance matrix — this skill re-derives taxonomy from raw amplicon sequences
- You need strain-level resolution or discrimination between intragenomic 16S gene copy variants — the Wang classifier against Greengenes resolves taxonomy, not within-genome copy variation
- Your reference database is not Greengenes and your question is database-agnostic — the failure rates reported here are conditional on classifying against each amplicon's source Greengenes database

## Inputs

- In-silico 16S amplicon FASTA sequences (per sub-region and full-length V1-V9, e.g., from task_001 primer extraction)
- Greengenes reference sequence alignment (FASTA)
- Greengenes reference taxonomy file
- Mapping of each amplicon to its source reference genome species

## Outputs

- Taxonomy assignments per amplicon at each confidence cutoff (30-98)
- Per-amplicon-region species-level failure-rate table (fig1b_species_failure_rates.csv)
- Comparison of computed failure rates against reported Fig. 1b values (V4 worst case: 56% species-level failure)

## How to apply

Load the in-silico amplicon FASTA sequences (generated by primer-based extraction from full-length reference 16S genes) together with the Greengenes reference alignment and taxonomy files. Run mothur's classify.seqs command, which implements the Wang Bayesian classifier, to assign each amplicon a taxonomic lineage against the Greengenes database. Sweep the classify.seqs confidence cutoff parameter across the range 30 to 98 so each amplicon receives taxonomy assignments at multiple thresholds, since species-level confidence depends heavily on this cutoff. For each cutoff, extract the deepest (species-level) label from the assigned lineage and compare it to the known source species of the reference genome from which the amplicon was derived. Compute the per-region species-level failure rate (fraction of amplicons whose species assignment differs from, or fails to reach, the source species) for each 16S sub-region and for the full-length V1-V9 amplicon; in this paper the V4 region performed worst, with 56% of in-silico amplicons failing to confidently match their source species, while full-length V1-V9 amplicons showed near-complete recovery.

## Related tools

- **mothur** (Provides the classify.seqs command with the Wang Bayesian classifier used to assign each in-silico amplicon a taxonomic lineage against the Greengenes reference database, with a confidence cutoff swept from 30 to 98)

## Examples

```
mothur "#classify.seqs(fasta=in_silico_v4_amplicons.fasta, reference=greengenes_ref.fasta, taxonomy=greengenes_ref_taxonomy.txt, cutoff=80)"
```

## Evaluation signals

- Reproduced V4 species-level failure rate is ~56%, matching Fig. 1b's reported worst case
- Full-length V1-V9 amplicons show near-complete species-level recovery relative to partial sub-regions
- Failure-rate table fig1b_species_failure_rates.csv contains one rate per 16S sub-region plus the full-length V1-V9 control
- Per-amplicon comparison confirms the assigned species label equals the known source species of the reference genome the amplicon was derived from (or records the failure)
- Cutoff sweep covers the full 30-98 range, demonstrating failure rates are reported conditional on confidence threshold

## Limitations

- Partial-sequencing accuracy is conditional on the reference database: amplicons were classified against the very Greengenes database from which they were derived, so real-community failure rates may be worse
- None of the variable regions covered by partial 16S sequencing recaptured the diversity represented by the full ~1500 bp gene
- The Wang classifier assigns lineages but cannot resolve intragenomic 16S copy variation or strain-level differences
