# deblur-observation-table-processing

## Summary

Loads a Deblur-generated exact-sequence BIOM observation table of 90-bp 16S V4 tag sequences, extracts the unique tag sequences, and (per the source task) aligns them against Greengenes 13.8 and SILVA 128 references with VSEARCH global alignment at 100% similarity to quantify reference recapture.

## When to use

Use when the input is a Deblur exact-sequence BIOM observation table of EMP-style 90-bp V4 tag sequences and the goal is to recover unique sequences for exact-match searches against reference databases such as Greengenes or SILVA.

## When NOT to use

- Input is an OTU-clustered table (closed- or open-reference picked against Greengenes 13.8/Silva 123) rather than Deblur exact sequences — exact 100%-identity matching is meaningless on consensus OTU IDs.
- Queries are not 90-bp V4 tag sequences (e.g., full-length amplicons or ITS sequences), since the skill's recapture metric is defined on Deblur V4 tags.
- The goal is approximate or partial sequence matching (identity < 1.0), which is outside the exact-sequence recapture design.

## Inputs

- Deblur 90-bp observation table (BIOM format) from EMP 16S Release 1 (~25,000 samples in 97 studies)
- Full-length Greengenes 13.8 reference sequence database (FASTA)
- SILVA 128 reference sequence database subset to non-eukaryotic (bacterial and archaeal) taxa (FASTA)

## Outputs

- Set of unique 90-bp V4 tag sequences (FASTA/query file)
- VSEARCH hit lists: reference sequences matched by at least one tag, and tag sequences matching at least one reference, per database
- reference_recapture_fractions.csv with four fractions: references recaptured and tags matched for Greengenes and SILVA

## How to apply

Load the complete Deblur 90-bp observation table (a BIOM table whose features are exact V4 sequences starting after primer 515f, generated by the Deblur exact-sequence de novo OTU picking method) and extract the set of unique tag sequences, applying the study's minimum-sequence-count filter (mc2 = an OTU must have at least 2 counts to be included). Run VSEARCH usearch_global in global alignment mode with --id 1.0, using the unique tag sequences as queries against full-length Greengenes 13.8 reference sequences. Repeat the same 100%-similarity global alignment against SILVA 128 references subset to non-eukaryotic (bacterial and archaeal) taxa. Count how many reference sequences are hit by at least one tag sequence and how many tag sequences match at least one reference in each database, then compute the fraction of references recaptured and the fraction of tags matching, writing the four fractions to reference_recapture_fractions.csv. The rationale is that EMP's coordinated protocols and exact-sequence (Deblur) rather than clustered-OTU representation allow bacterial and archaeal rRNA gene sequences to be compared across ~100 environmental surveys, so exact-match alignment directly measures how much standing reference diversity the catalogue recaptures.

## Evaluation signals

- The four fractions in reference_recapture_fractions.csv reproduce the published values: 46% of Greengenes and 45% of SILVA reference sequences recaptured; 10% and 13% of tag sequences matching, respectively.
- Every query alignment is run with --id 1.0 (global alignment at 100% similarity); any hits at lower identity indicate the search was misconfigured.
- The SILVA comparison is restricted to non-eukaryotic (bacterial and archaeal) taxa before counting hits.
- The unique tag-sequence set is exactly 90 bp, V4 region starting after primer 515f, consistent with Deblur tag sequences.
- OTU/feature filtering enforces the mc2 rule (minimum sequence count in an OTU to be included equals 2).

## Limitations

- Only exact (100% similarity) global matches are counted, so the recapture fraction is a lower bound on true sequence overlap; near-matches are excluded by design.
- Results depend on the database version (Greengenes 13.8, SILVA 128) and on subsetting SILVA to non-eukaryotic taxa; other versions or subsets will change the fractions.
- EMP 16S Release 1 covers ~25,000 samples in 97 studies processed with Deblur; tables produced by closed-reference OTU picking (Greengenes 13.8 or Silva 123) or other pipelines are not comparable inputs.
