# classifier-disagreement-analysis

## Summary

Benchmark taxonomic classifiers (vsearch-SINTAX, q2-feature-classifier's BLAST+LCA and VSEARCH+LCA, Naive Bayes, and the BOLD Classification API) on mock community and bat guano COI ASVs, computing Taxonomic Accuracy Rate (TAR) and Taxonomic Discovery Rate (TDR) per rank and tallying common vs. distinct assigned names to expose underclassification by the BOLD API.

## When to use

Use when a metabarcoding study needs to compare relative completeness and accuracy of multiple taxonomic classifiers on COI amplicon data, or when investigating why one classifier (e.g., BOLD API) assigns fewer taxa than others.

## When NOT to use

- Input data is not a COI amplicon animal diet metabarcoding dataset (the benchmark, databases, and mock community expectations are COI/arthropod-specific)
- The analysis goal is denoising or sequence filtering rather than comparing taxonomic classification outputs — use the sequence filtering or database construction skills instead
- Only a single classifier is in scope and no relative completeness/accuracy comparison or disagreement diagnosis is needed

## Inputs

- Mock community amplicon sequences (CFMR_insect_mock4_wtax_noIM52) with expected taxa
- DADA2-filtered bat guano ASV sequences (13,407 unique sequences, basic filtering)
- tidybug BOLD COI reference database (boldCOI.derep.seqs.qza and boldCOI.derep.tax.qza)
- SINTAX-formatted reference database (tmp_forSINTAX.fasta.gz)
- Pre-trained Naive Bayes classifier (nbClassifer_allboldDB.qza)

## Outputs

- Per-classifier taxonomy assignments at 95/97/99% identity and 0.3–0.9 confidence thresholds
- TAR and TDR values per classifier per taxonomic rank (class through species)
- Tallies of common and distinct taxonomic names assigned per rank for guano ASVs
- Comparison figures generated by figure6_classifier_MockComps.R, figure7_classifier_GuanoComparisons.R, and figureS4_classifier_Consequence.R

## How to apply

Classify the mock community sequences (CFMR_insect_mock4_wtax_noIM52) against the tidybug BOLD COI database (boldCOI.derep.seqs.qza / boldCOI.derep.tax.qza) using classify-consensus-blast and classify-consensus-vsearch with --p-maxaccepts 1000, --p-query-cov 0.89, and 0.95/0.97/0.99 percent identity thresholds; also run the Naive Bayes scikit-learn classifier (nbClassifer_allboldDB.qza) at 0.3–0.9 confidence and VSEARCH v2.13.4 SINTAX with --sintax_cutoff 0.3–0.9. Classify the same sequences via the BOLD API through the ropensci/bold R package, retaining hits above 95%, 97%, or 99% identity and applying an LCA to remaining hits because the API does not report query coverage. Apply all classifiers to the DADA2-filtered guano ASVs (13,407 unique sequences) using a 97% identity and 70% confidence threshold, batching BOLD queries through boldAPI_classification.R. Compute TAR = TP/(TP+FP) and TDR = TP/(TP+FN) per rank from class through species against expected mock taxa, and tally common/distinct names per rank for guano ASVs, following up ASVs where non-BOLD classifiers assign a species but BOLD does not to distinguish classifier failure from database composition issues. Visualize with figure6_classifier_MockComps.R, figure7_classifier_GuanoComparisons.R, and figureS4_classifier_Consequence.R.

## Examples

```
vsearch --sintax mock_asvs.fasta --db tmp_forSINTAX.fasta.gz --sintax_cutoff 0.7 --tabbed mock_sintax.tsv
```

## Evaluation signals

- The BOLD API reports the lowest number of named taxa at every taxonomic rank (order through species) compared to vsearch-SINTAX, BLAST+LCA, VSEARCH+LCA, and Naive Bayes, on both mock community and bat guano data
- TAR/TDR values per rank against expected mock taxa match the reported classifier benchmark across class, order, family, genus, and species levels
- Common and distinct name tallies per rank for guano ASVs reconcile across classifiers without unexplained duplicated or missing taxon strings
- For ASVs where all non-BOLD classifiers assign a species but BOLD does not, the missing species is checked against other BOLD-classified ASVs to separate classifier failure from database composition gaps
- Mock community classification reproduces expected taxa, giving TP/FP/FN counts consistent with the published TAR = TP/(TP+FP) and TDR = TP/(TP+FN) definitions

## Limitations

- The BOLD Classification API is closed-source: it does not document its classification parameters or the content of its reference database, so what drives missing assignments is unclear
- BOLD API output does not provide query coverage, so an LCA process had to be applied to remaining hits, and it is unclear whether the tidybug database contents were identical to those used by the API
- No attempt was made to determine how pervasive BOLD records lacking Phylum/Class information are, and BOLD discontinued packaged versioned releases in 2015, hampering reproducibility
- No single curated and versioned COI reference database resource is widely used in animal diet studies, making cross-study comparisons difficult

## Evidence

- [abstract] BOLD API underclassifies relative to other classifiers: "the commonly used Barcode of Life Database (BOLD) Classification API assigned fewer names to samples from order through species levels using both a mock community and bat guano samples"
- [methods] BOLD API parameters undocumented: "which does not provide details about specific parameters invoked during classification, nor does it specify the content of the database used for it's classification"
- [methods] LCA applied to BOLD hits due to missing query coverage: "Because query coverage was not a parameter that was provided in the output, we applied an LCA process to those remaining hits"
- [results] Missing assignments unexplained: "Because their API uses a closed source reference database and classification parameters are undefined, it is unclear exactly what proportion of these missing assignments"
- [intro] Benchmark scope of the study: "We benchmarked taxonomic classification using both a mock community and bat guano samples to evaluate relative classifier completeness and accuracy"
