# paired-t-test-error-comparison

## Summary

Statistical comparison of species-level classification error rates between uniform and bespoke (habitat-specific) taxonomic weights, using paired t-tests averaged across the 14 EMPO 3 habitats, as done for the Proteobacteria/Firmicutes results in Supplementary Fig. 5 of the q2-clawback paper.

## When to use

Use when comparing classification error rates of two weighting schemes (e.g., uniform vs bespoke taxonomic weights) evaluated on the same test sequence variants and you need a paired significance test per taxon plus a per-phylum error-rate table.

## When NOT to use

- When the two weighting schemes were evaluated on different test sequence variants or different habitats — the pairing that the t-test assumes would be broken
- When sample weights cannot be assembled for the habitat of interest (natural sample types lacking sufficient characterization for bespoke weight assembly); average weights or another comparison is more appropriate
- When the question is genus- or phylum-level error rather than species-level, since the reported improvements are specific to species-level classification

## Inputs

- Species-level classification error rates per EMPO 3 habitat under uniform weights (paired observations)
- Species-level classification error rates per EMPO 3 habitat under bespoke habitat-specific weights (paired observations)
- Phylum assignment of test sequence variants (Proteobacteria, Firmicutes)
- Optional: precomputed bespoke class weights from the readytowear repository instead of rerunning clawback

## Outputs

- supplementary_fig5_error_rates.csv with per-phylum error rates and paired t-test P-values
- Per-phylum mean error rates (Proteobacteria: 35.4% ±0.7% uniform vs 22.3% ±0.4% bespoke; Firmicutes: 43.6% ±0.7% uniform vs 24.3% ±0.3% bespoke)

## How to apply

Train q2-feature-classifier naive Bayes classifiers twice on the same reference database (e.g., Greengenes/Silva 138.1): once with uniform species weights and once with bespoke habitat-specific weights generated by q2-clawback (or loaded from the readytowear repository). Classify the test sequence variants from each of the 14 EMPO 3 habitats under both schemes and compute species-level error rates per phylum (Proteobacteria, Firmicutes) per habitat, giving paired observations across habitats. Average the error rates across the 14 habitats and run a paired t-test (e.g., scipy.stats.ttest_rel on per-habitat error pairs) comparing uniform vs bespoke error per phylum. Write the per-phylum error rates and P-values to a CSV such as supplementary_fig5_error_rates.csv; validate against expected drops (Proteobacteria ~35.4% -> ~22.3%, P ≈ 1.4e-6; Firmicutes ~43.6% -> ~24.3%, P ≈ 8.4e-6).

## Related tools

- **q2-clawback** (Generates the bespoke habitat-specific class weights whose error rates are compared against uniform weights via the paired t-test) — github.com/BenKaehler/q2-clawback
- **q2-feature-classifier** (Trains the naive Bayes classifiers (uniform vs bespoke weights) and classifies test sequence variants to produce the error rates being tested)

## Examples

```
from scipy.stats import ttest_rel; t, p = ttest_rel(uniform_err_per_habitat, bespoke_err_per_habitat)
```

## Evaluation signals

- Bespoke weighting drops Proteobacteria species-level error from ~35.4% (±0.7% s.e.) to ~22.3% (±0.4% s.e.) with paired t-test P ≈ 1.4e-6
- Bespoke weighting drops Firmicutes species-level error from ~43.6% (±0.7% s.e.) to ~24.3% (±0.3% s.e.) with paired t-test P ≈ 8.4e-6
- Error pairs are genuinely paired: same test sequence variants and same 14 EMPO 3 habitats under both weighting schemes
- supplementary_fig5_error_rates.csv contains both per-phylum error rates and P-values and matches the Supplementary Fig. 5 values
- Overall species-level average error should decline on the order of 25% -> 14% under bespoke weighting, consistent with the paper's headline result

## Limitations

- Performance degradation was observed for rare species under bespoke weighting
- Bespoke classification is not immune to errors from poorly curated reference data (e.g., reference sequence misannotation)
- Empirical species distributions introduce potential error sources such as misannotated sample types and sequencing biases propagated into the taxonomic weights
