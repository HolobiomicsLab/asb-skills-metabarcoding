# pairwise-group-significance-testing-of-beta-diversity

## Summary

In the EasyAmplicon pipeline, beta diversity distance matrices (Bray-Curtis, Euclidean, UniFrac) computed with USEARCH -beta_div are ordinated by PCoA via the beta_pcoa.R script, and the analysis additionally reports pairwise between-group comparison p-values written to beta_pcoa_stat.txt.

## When to use

Use when a rarefied OTU/feature table and sample metadata are available and you need an ordination plot plus statistical p-values for every pairwise group comparison of community composition differences.

## When NOT to use

- The input is raw reads or an unrarefied table — depth must be standardized by rarefaction before beta diversity distances are comparable
- The metadata lacks a defined grouping column (e.g., Group), so no pairwise between-group comparison can be defined
- The goal is taxonomy or functional profiling (STAMP, PICRUSt2) rather than community-composition ordination and significance testing

## Inputs

- rarefied feature/OTU table (result/otutab_rare.txt)
- sample metadata/design file with a grouping column (result/metadata.txt, Group column)
- phylogenetic tree of representative sequences (result/otus.tree, from usearch -cluster_agg)
- representative OTU sequences (result/otus.fa)
- distance matrix (result/beta/bray_curtis.txt, generated by usearch -beta_div)

## Outputs

- PCoA ordination plot (result/beta/bray_curtis.pcoa.pdf / pcoa_bray_curtis.pdf), samples colored by Group
- pairwise group comparison p-values table (result/beta/beta_pcoa_stat.txt)
- inter-sample distance matrices under result/beta/ prefix (Bray-Curtis, Euclidean, UniFrac and related)

## How to apply

First generate inter-sample distance matrices from the rarefied table (result/otutab_rare.txt) using `usearch -beta_div result/otutab_rare.txt -tree result/otus.tree -filename_prefix result/beta/`, where the tree comes from `usearch -cluster_agg result/otus.fa -treeout result/otus.tree`. Then ordinate the Bray-Curtis matrix with the EasyMicrobiome R script: `Rscript ${db}/script/beta_pcoa.R --input result/beta/bray_curtis.txt --design result/metadata.txt --group Group --output result/beta/bray_curtis.pcoa.pdf`, coloring samples by the Group column of result/metadata.txt. During the same step, compute pairwise between-group significance p-values from the ordination/distance analysis and write them to result/beta/beta_pcoa_stat.txt. Correct application requires the distance matrix column count to equal the number of samples in the metadata, the PCoA PDF to be produced, and beta_pcoa_stat.txt to contain a p-value for each pairwise group comparison.

## Related tools

- **USEARCH** (computes inter-sample beta-diversity distance matrices (Bray-Curtis, Euclidean, UniFrac) from the rarefied table using the phylogenetic tree (-beta_div))
- **EasyAmplicon** (pipeline that packages the beta_pcoa.R workflow producing the PCoA plot and beta_pcoa_stat.txt p-values) — https://github.com/YongxinLiu/EasyAmplicon
- **EasyMicrobiome** (provides the R scripts (e.g., beta_pcoa.R) and databases referenced by ${db}/script in the ordination step) — https://github.com/YongxinLiu/EasyMicrobiome

## Examples

```
Rscript ${db}/script/beta_pcoa.R --input result/beta/bray_curtis.txt --design result/metadata.txt --group Group --output result/beta/bray_curtis.pcoa.pdf
```

## Evaluation signals

- Distance matrix column count equals the number of samples in result/metadata.txt
- result/beta/bray_curtis.pcoa.pdf is generated and samples are colored by the Group column
- result/beta/beta_pcoa_stat.txt exists and contains a p-value for each pairwise group comparison
- Distance matrices for Bray-Curtis, Euclidean and UniFrac are all written under the result/beta/ filename prefix
- The tree used with -beta_div was built from the same representative sequences (result/otus.fa) used for OTU clustering

## Limitations

- The p-value file (beta_pcoa_stat.txt) covers pairwise group comparisons only; the paper text does not state correction for multiple testing
- UniFrac and other tree-based distances depend on the USEARCH hierarchical average-linkage tree (-cluster_agg); errors in tree building propagate to the distances
- The protocol discussion notes no limitations section and no changelog, so version-specific behavior of the beta_pcoa.R script is not documented
