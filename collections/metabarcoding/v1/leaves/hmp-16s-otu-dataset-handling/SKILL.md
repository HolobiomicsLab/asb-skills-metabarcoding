# hmp-16s-otu-dataset-handling

## Summary

Handles the HMP V1V3 and V3V5 16S rRNA OTU datasets generated by QIIME with a 97% percent-sequence-similarity (PSD) threshold, organizing read-to-representative pairwise MSD and BLD dissimilarities for downstream metric comparisons.

## When to use

Use when analysis input consists of HMP-derived 16S rRNA OTU datasets (V1V3 or V3V5 hypervariable regions) clustered at 97% sequence similarity, and per-OTU representative-to-member sequence relationships must be loaded for dissimilarity (MSD/BLD) computations or regional comparisons.

## When NOT to use

- Input is raw sequencing data (FASTQ) or an amplicon dataset not yet clustered into OTUs — this skill operates on already-clustered HMP OTU datasets, not upstream clustering itself.
- Input is a feature table or abundance data where per-sequence representative-member relationships are absent; MSD/BLD read-to-representative pairing cannot be constructed.
- Analysis concerns taxonomic annotation of representative sequences rather than quantitative dissimilarity handling — the annotation step is a separate workflow.

## Inputs

- HMP V1V3 OTU dataset (QIIME-generated, 97% PSD clustering threshold)
- HMP V3V5 OTU dataset (QIIME-generated, 97% PSD clustering threshold)
- Precomputed pairwise MSD dissimilarity values between each representative sequence and all member sequences
- Precomputed pairwise BLD dissimilarity values between each representative sequence and all member sequences

## Outputs

- Per-region (V1V3, V3V5) paired (MSD, BLD) dissimilarity vectors across all read-to-representative pairs
- Per-OTU aggregates of mean MSD and mean BLD keyed to each OTU's representative sequence
- correlation_results.csv with Pearson correlation coefficients plus region and level labels

## How to apply

Load the HMP V1V3 and V3V5 OTU datasets, which were computed by QIIME using PSD at a 97% sequence similarity threshold. For each OTU, identify the single selected representative sequence and all remaining member sequences, then pair these with the precomputed MSD and BLD dissimilarity values between each representative and all members (produced by the upstream distance-computation step). Keep the two hypervariable regions (V1V3 and V3V5) separate throughout, since their dissimilarity structure differs — e.g., 80.5% of V3V5 OTUs had at least one sequence with MSD>0.03 from the representative. Assemble paired (MSD, BLD) vectors per region across all read-to-representative pairs before any aggregation to the OTU level, so both read-level and OTU-level analyses remain reproducible from the same loaded data.

## Related tools

- **QIIME** (Pipeline that generated the HMP OTU datasets from which V1V3 and V3V5 OTUs and representative sequences are handled) — github.com/namphuon/phylo
- **mothur** (Alternative end-to-end 16S pipeline referenced in the article for generating comparable OTU datasets)

## Examples

```
import scipy.stats as ss; r, p = ss.pearsonr(msd_v3v5, bld_v3v5); r_otu, p_otu = ss.pearsonr(msd_v3v5_otu_mean, bld_v3v5_otu_mean)
```

## Evaluation signals

- Each OTU maps to exactly one representative sequence, and every remaining OTU sequence has both an MSD and BLD dissimilarity value against that representative.
- V1V3 and V3V5 data are never merged; all downstream statistics (e.g., Pearson r) are computed per region.
- Recomputed read-level correlations match the reported values: r = 0.10 for V3V5 and r = 0.38 for V1V3.
- OTU-level (mean-per-OTU) correlations match the reported values: r = 0.41 for V3V5 and r = 0.63 for V1V3, both exceeding the read-level correlations.
- correlation_results.csv contains exactly four coefficient rows labeled with region (V1V3/V3V5) and level (read/OTU).

## Limitations

- OTUs were built with PSD at 97% similarity, which is only a rough approximation for delineating species, so cluster quality is bounded by that threshold.
- Poorly clustered OTUs can bias results because OTUs are annotated based on a single representative sequence; 80.5% of V3V5 OTUs had at least one sequence with MSD>0.03 from the representative.
- Percent sequence similarity (PSD) can overestimate evolutionary similarity, which is why MSD and BLD are re-measured rather than reusing PSD values.
