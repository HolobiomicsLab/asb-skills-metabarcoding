# COI-reference-database-formatting

## Summary

Build and format a bespoke COI reference database for OBITools-based taxonomic assignment of MOTU representative sequences, combining all COI elasmobranch sequences retrieved from BOLD with non-elasmobranch decoy sequences obtained by in silico PCR (ecoPCR) against EMBL release R117.

## When to use

Use when MOTU representative sequences (e.g. sumaclust 99% clusters) must be taxonomically assigned with ecotag and the underlying COI reference database must be assembled from BOLD and formatted for the OBITools suite.

## When NOT to use

- Input is not COI metabarcoding data or the amplicon is a longer fragment designed to resolve closely related species — this database targets the ~127 bp Fields et al. (2015) elasmobranch COI primer set
- Sequences have not yet been clustered into MOTUs (sumaclust 99%) and single-read MOTUs removed — assignment should follow MOTU delimitation
- A curated, complete reference database for the taxonomic group already exists in OBITools format, making bespoke BOLD+ecoPCR assembly redundant

## Inputs

- BOLD COI elasmobranch sequences (retrieved via custom R script from boldsystems.org)
- Non-elasmobranch COI sequences from in silico PCR (ecoPCR) against EMBL-EBI release R117
- MOTU representative sequences from sumaclust 99% clustering (single-read MOTUs removed), in FASTA

## Outputs

- OBITools-formatted combined COI reference database (FASTA plus obitax/ecoPCR-format index)
- ecotag per-MOTU taxonomic assignment table (MOTU ID, read counts per sample, assigned taxonomy)
- Publicly archived reference database at github.com/metabarpark/Reference-databases

## How to apply

Retrieve all COI elasmobranch sequences available from the BOLD database (boldsystems.org) with a custom R script, and complement them with non-elasmobranch COI sequences generated by an in silico PCR (ecoPCR) against release R117 of the EMBL-EBI database so that non-target amplifications can be flagged. Convert the resulting combined FASTA into OBITools-compatible indexed formats using ecoPCR-format/obitax so ecotag can resolve the most specific consistent taxon per MOTU. Publish the combined reference database (github.com/metabarpark/Reference-databases) and join the ecotag output into a per-MOTU assignment table with MOTU IDs, per-sample read counts, and taxonomy. Note the resolution limit: at the 127 bp COI fragment length, some MOTUs match 100% to multiple BOLD species and must be treated as split Pacific/Caribbean components rather than forced one-to-one species calls.

## Related tools

- **OBITools** (Suite used to format the combined reference database (ecoPCR-format/obitax) and host the ecotag assignment algorithm) — github.com/metabarpark/Reference-databases
- **ecoPCR** (Performs in silico PCR against EMBL-EBI release R117 to supply non-elasmobranch reference sequences for the combined database)
- **ecotag** (Assigns the most specific consistent taxon to each MOTU representative sequence against the formatted combined reference database) — github.com/metabarpark/Reference-databases

## Evaluation signals

- The OBITools-formatted database loads without error under obitax and indexes correctly with ecoPCR-format
- The ecotag assignment table contains one row per MOTU with taxonomy fields populated
- The elasmobranch taxa contributing to the 21 reported shark species are present in the assignment table
- MOTUs with 100% identity matches to more than one BOLD species are explicitly flagged/split into Pacific and Caribbean components rather than silently collapsed
- The combined database is publicly retrievable from github.com/metabarpark/Reference-databases

## Limitations

- Taxonomic resolution of the 127 bp COI fragment is insufficient to separate closely related species (e.g. Carcharhinus, Rhizoprionodon, Negaprion); some MOTUs are 100% identical to multiple species in BOLD, including species from different ocean regions
- Certain elasmobranch species present at sampling (e.g. Ginglymostoma cirratum, observed visually) may be missed entirely due to primer mismatches against the reference/primers
- A trade-off exists between taxonomic resolution and non-target amplification, which must be balanced before informing conservation decisions
