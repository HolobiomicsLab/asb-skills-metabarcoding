# VSEARCH global alignment exact-sequence matching

## Summary

Recapture reference-database sequence diversity by globally aligning exact Deblur 90-bp V4 tag sequences against full-length 16S rRNA references (Greengenes 13.8, SILVA 128) with VSEARCH at 100% similarity, quantifying the fraction of reference sequences hit by environmental survey data.

## When to use

Use when you need to quantify what fraction of a reference database (e.g., Greengenes 13.8, SILVA) is recaptured by exact sequences from an observational dataset, using global alignment at 100% similarity.

## When NOT to use

- When approximate or partial matches are of interest — this skill is defined at exactly 100% similarity (--id 1.0); clustered OTU picking or lower identity thresholds are different analyses
- When queries are not exact-sequence features (e.g., clustered OTU representative sequences) — results reflect Deblur exact tag sequence diversity, not OTU diversity

## Inputs

- Deblur 90-bp observation table (BIOM) of EMP tag sequences (V4 region, starting after primer 515f)
- Full-length Greengenes 13.8 16S rRNA reference sequences (FASTA)
- SILVA 128 reference sequences subset to non-eukaryotic (bacterial and archaeal) taxa (FASTA)

## Outputs

- reference_recapture_fractions.csv containing four fractions: fraction of Greengenes and SILVA references recaptured, and fraction of tag sequences matching each database
- VSEARCH hit lists (references hit by >=1 tag; tags matching >=1 reference) per database

## How to apply

Load the complete Deblur 90-bp observation table (V4 region starting after primer 515f) and extract the set of unique tag sequences generated by the exact-sequence Deblur algorithm. Run VSEARCH usearch_global in global alignment mode with --id 1.0, using the unique tag sequences as queries against full-length Greengenes 13.8 reference sequences, then repeat against SILVA 128 references subset to non-eukaryotic (bacterial and archaeal) taxa. Global alignment is essential so query and reference sequences are compared end-to-end, allowing a 90-bp tag to hit a full-length rRNA reference anywhere along its length. Count how many reference sequences are hit by at least one tag sequence and how many tag sequences match at least one reference sequence per database. Compute the fraction of references recaptured and the fraction of tags matching, writing the four fractions to a CSV and validating against published values.

## Related tools

- **VSEARCH** (Performs usearch_global global alignment of Deblur tag sequences against reference databases at 100% similarity (--id 1.0))
- **Deblur** (Generates the exact-sequence (de novo) 90-bp V4 tag sequences used as alignment queries) — https://github.com/cuttlefishh/deblur
- **Python** (Loads the BIOM observation table, extracts unique tag sequences, and computes/writes the recapture fractions)

## Examples

```
vsearch --usearch_global emp_deblur_90_unique.fna --db greengenes13_8.fna --id 1.0 --blastnout gg_hits.txt --threads 8
```

## Evaluation signals

- Computed recapture fractions reproduce published values: 46% of Greengenes 13.8 and 45% of SILVA references recaptured
- Tag-matching fractions match published values: ~10% of tags match Greengenes and ~13% match SILVA
- reference_recapture_fractions.csv contains exactly four fractions (per-database reference-recaptured and tag-matched)
- Alignment log confirms --id 1.0 (100% similarity) with global (usearch_global) alignment mode for both databases
- SILVA reference set is confirmed subset to non-eukaryotic (bacterial and archaeal) taxa before counting

## Limitations

- Only exact-sequence (100% similarity) matches are detected; novel or divergent reference diversity is invisible to this metric
- 90-bp tag sequences are short relative to full-length references, so coverage of reference sequence space depends entirely on the V4 region sampled
- Reference databases must be filtered to non-eukaryotic taxa for comparable results (SILVA 128 subset used here)
