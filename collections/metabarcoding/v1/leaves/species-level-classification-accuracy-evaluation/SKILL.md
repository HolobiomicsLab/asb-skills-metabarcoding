# species-level-classification-accuracy-evaluation

## Summary

Benchmark for comparing bespoke (habitat-specific) species-level taxonomic classification against uniform-weight genus-level classification of marker-gene amplicon sequences, using per-sample error rates and Bray-Curtis dissimilarity against known ground-truth taxonomies, replicating the Fig. 1 evaluation of Kaehler et al. 2019 (Nat Commun 10:4643).

## When to use

Use when amplicon (e.g. 16S V4) test sequences have known ground-truth taxonomies and you need to quantify whether environment-specific bespoke weights at species level outperform uniform weights at genus level.

## When NOT to use

- Test samples lack ground-truth taxonomies, so per-sample error rates and Bray-Curtis against true compositions cannot be computed
- The query sample's environment has no characterized samples from which bespoke weights can be assembled (use global-average weights instead of uniform, per the paper)
- Input is not marker-gene amplicon data classified against a reference like Greengenes (e.g. whole-genome or metagenomic data), where a naive Bayes amplicon classifier benchmark does not apply

## Inputs

- Pre-fitted naive Bayes classifier trained on Greengenes 13_8 99% OTU reference (q2-feature-classifier .qza artifact)
- Bespoke (Qiita-derived) class weights per habitat type from the readytowear repository (EMPO 3 habitats)
- Test amplicon sequences with known ground-truth taxonomies (per EMPO 3 habitat type)
- Uniform class weights (or absence of weights) for the genus-level baseline condition

## Outputs

- Per-sample error rates at species level (bespoke) and genus level (uniform)
- Bray-Curtis dissimilarities between predicted and true community compositions per condition
- Single-sided paired t-test t-statistics and P-values (error rate and Bray-Curtis comparisons)
- fig1_comparison.csv with mean error rates, mean Bray-Curtis dissimilarities, t-statistics, and P-values

## How to apply

Load a pre-fitted Greengenes 13_8 99% OTU naive Bayes classifier from q2-feature-classifier and the per-environment bespoke class weights (e.g. for the 14 EMPO 3 habitat types) from the readytowear repository, which are generated by q2-clawback. Classify each test sequence set twice with q2-feature-classifier's classify-sklearn: once at species level using Qiita-derived bespoke weights and once at genus level using uniform weights. Compute per-sample classification error rates by comparing predicted taxonomies to ground-truth taxonomies at the respective taxonomic level, then compute Bray-Curtis dissimilarity between predicted and true community compositions for each condition. Run a single-sided paired t-test matching bespoke species-level against uniform genus-level error rates (and likewise for Bray-Curtis values) across matched samples, and compile mean error rates, mean Bray-Curtis dissimilarities, t-statistics and P-values into fig1_comparison.csv. Validation targets from the paper: mean species-level bespoke error ~14% vs genus-level uniform ~16%, mean Bray-Curtis 0.13 (bespoke species) vs 0.15 (uniform genus), paired t-test P = 0.013.

## Examples

```
qiime feature-classifier classify-sklearn --i-classifier gg99-classifier.qza --p-classify--weights bespoke-weights.qza --i-reads test-reads.qza --o-classification species-taxonomy.qza
```

## Evaluation signals

- Mean species-level bespoke error rate is approximately 14% across the 14 EMPO 3 habitat types
- Mean genus-level uniform error rate is approximately 16%
- Mean Bray-Curtis dissimilarity is approximately 0.13 for bespoke species-level vs 0.15 for uniform genus-level classification
- Single-sided paired t-test comparing bespoke species-level vs uniform genus-level error rates yields P ≈ 0.013
- fig1_comparison.csv contains per-condition mean error rates, mean Bray-Curtis dissimilarities, t-statistics, and P-values matching Fig. 1 of the paper

## Limitations

- Classification accuracy degrades linearly with the degree to which the equal-likelihood assumption for reference species is violated, and the assumption is practically always violated
- Performance degradation was observed for rare species under bespoke weighting
- Bespoke classification is not immune to errors from poorly curated reference data (e.g. reference sequence misannotation), and empirical species distributions can propagate misannotated sample types and sequencing biases into the weights
