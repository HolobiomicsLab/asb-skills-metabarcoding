# tar-tdr-metric-computation

## Summary

Computes Taxonomic Accuracy Rate (TAR = true positives / (true positives + false positives)) and Taxonomic Discovery Rate (TDR = true positives / (true positives + false negatives)) per taxonomic rank to benchmark taxonomic classifiers (vsearch-SINTAX, q2 BLAST+LCA and VSEARCH+LCA, Naive Bayes, BOLD API) against mock community expected taxa and guano sample assignments.

## When to use

Use when benchmarking taxonomic classifiers against a mock community with known expected taxa and you need per-rank completeness (TDR) and accuracy (TAR) metrics to compare classifier assignments.

## When NOT to use

- The dataset has no known expected taxa (e.g. environmental samples alone), so true positives/false negatives for TDR cannot be defined — the metrics require a mock community ground truth.
- You only need a single classifier's taxonomy output rather than a comparative benchmark across classifiers and ranks.
- Sequences have not yet been denoised/clustered into representative sequences — classification and TAR/TDR scoring come after the ASV/OTU inference step.

## Inputs

- Mock community amplicon sequences with expected taxa (CFMR_insect_mock4_wtax_noIM52)
- Per-classifier taxonomy assignments (QIIME 2 .qza taxonomies, SINTAX output, BOLD API JSON/CSV results)
- DADA2-filtered bat guano ASV feature table (13,407 unique sequences)
- Reference database files for classification (boldCOI.derep.seqs.qza / boldCOI.derep.tax.qza, tmp_forSINTAX.fasta.gz, nbClassifer_allboldDB.qza)

## Outputs

- Per-rank TAR and TDR values (class through species) for each classifier
- Tallies of common and distinct taxonomic names assigned per rank across classifiers for guano ASVs
- Comparison figures generated by figure6_classifier_MockComps.R, figure7_classifier_GuanoComparisons.R, and figureS4_classifier_Consequence.R

## How to apply

Classify the mock community sequences (CFMR_insect_mock4_wtax_noIM52) with each classifier — q2-feature-classifier classify-consensus-blast/vsearch (--p-maxaccepts 1000, --p-query-cov 0.89, identities 0.95/0.97/0.99), Naive Bayes at confidences 0.3–0.9, vsearch-SINTAX at --sintax_cutoff 0.3–0.9, and the BOLD API via the bold R package with 95/97/99% identity cutoffs and an LCA over remaining hits. For the bat guano dataset, classify the DADA2-filtered 13,407 ASVs with all classifiers at a 97% identity threshold and 70% confidence threshold, batching BOLD API queries through boldAPI_classification.R. Compare each classifier's assignments from class through species rank against the expected mock taxa to tally true positives, false positives, and false negatives, then compute TAR = TP/(TP+FP) and TDR = TP/(TP+FN) per rank. Separately tally common and distinct taxonomic names per rank across classifiers for the guano ASVs, and investigate ASVs where all non-BOLD classifiers assigned a species but BOLD did not to distinguish classifier failure from database composition issues. Process per-classifier outputs with figure6_classifier_MockComps.R, figure7_classifier_GuanoComparisons.R, and figureS4_classifier_Consequence.R to generate the comparison figures.

## Evaluation signals

- TAR and TDR values per rank (class through species) match the reported classifier benchmark for the mock community
- The BOLD classifier shows the lowest number of named taxa at every taxonomic rank among all classifiers on the bat guano data, and fewer names than all other classifiers at order through species levels on both mock and guano samples
- Per-rank tallies of common and distinct taxonomic names across classifiers are reproducible from the per-classifier taxonomy outputs
- ASVs where all non-BOLD classifiers assigned a species but BOLD did not are checked against other BOLD-classified ASVs to distinguish classifier failure from database composition issues
- Figures produced by figure6_classifier_MockComps.R and figure7_classifier_GuanoComparisons.R reproduce the published classifier comparison plots

## Limitations

- The BOLD API is closed source: its classification parameters and the content of the database it uses are undefined, so the cause of missing assignments cannot be fully determined
- BOLD API output does not provide query coverage, so an LCA was applied to remaining hits; it is also unclear whether the tidybug database contents matched those used by the BOLD API
- No attempt was made to determine the prevalence of BOLD records lacking Phylum/Class information, and the paper's aim is not to present a single best pipeline but to illustrate effects of program/parameter choices
