# in-silico-amplicon-diversity-comparison

## Summary

Quantifies how many OTUs are recovered from in-silico 16S sub-region amplicons at 97%, 98%, and 99% identity thresholds, and benchmarks these counts against the number of distinct full-length (~1500 bp) sequences in the source database to test whether partial 16S regions recapture full gene diversity.

## When to use

Use when you have in-silico 16S amplicon FASTA files per sub-region and need to measure how clustering threshold and sub-region choice (e.g. V4) affect OTU counts relative to distinct full-length 16S sequences.

## When NOT to use

- Input is a real sequencing run (FASTQ reads from a mock or in-vivo community) rather than in-silico amplicons from a curated sequence database — the comparison against distinct full-length source sequences only makes sense for the in-silico design.
- You need strain- or species-level taxonomic assignment of actual communities; this skill only quantifies diversity recapture via OTU counts, not abundance or classification accuracy.
- Chimera detection is required for your downstream analysis — this skill explicitly disables -uchime_denovo so OTU counts are not chimera-filtered.

## Inputs

- In-silico 16S sub-region amplicon FASTA files (one per sub-region, e.g. V1-V3, V4, V1-V9 from task_001)
- Source database of distinct full-length 16S ~1500 bp sequences with known distinct-sequence count

## Outputs

- otu_counts.csv — table of per-region, per-threshold (0.97/0.98/0.99) OTU counts
- Per-region OTU FASTA / OTU count values at each identity threshold

## How to apply

Load the in-silico amplicon FASTA files for each 16S sub-region (generated by the in-silico priming/amplicon task). For each sub-region, run USEARCH cluster_otus at 97% identity (-id 0.97), then repeat at 98% (-id 0.98) and 99% (-id 0.99), deliberately disabling chimera detection (no -uchime_denovo step) so counts reflect pure sequence-space clustering. Record the OTU count per region per threshold and compile them into a single table (otu_counts.csv). Compare each sub-region's OTU count at 99% identity against the original number of distinct full-length sequences: in this study no sub-region recaptured the source diversity, with the V4 region performing worst, because short variable regions cannot match the taxonomic resolution of the full ~1500 bp gene. Verify the tabulated counts reproduce the values plotted in Fig. 1d and Supplementary Fig. 3 of the article.

## Related tools

- **USEARCH** (Clustering sub-region amplicons into OTUs at 97%, 98%, and 99% identity thresholds via cluster_otus with chimera detection disabled)
- **ruffus** (Python pipeline framework used to orchestrate the per-figure analysis pipelines, including the Fig. 1 in-silico OTU clustering workflow) — https://github.com/cgat-developers/ruffus

## Examples

```
usearch -cluster_otus v4_amplicons.fasta -id 0.99 -otus v4_otus.fasta -uc v4_otus.uc
```

## Evaluation signals

- For every sub-region, the OTU count at 99% identity is strictly less than the number of distinct full-length sequences in the source database (no region recaptures full diversity).
- The V4 region yields the worst recapture (largest shortfall from the distinct full-length sequence count) among tested sub-regions.
- The compiled otu_counts.csv contains all 3 thresholds × all sub-regions and the values reproduce the points plotted in Fig. 1d and Supplementary Fig. 3.
- Chimera detection was omitted: no -uchime_denovo step appears in the clustering runs, and OTU counts were produced directly by cluster_otus at each -id value.
- The analysis code runs under the repository's ruffus pipeline framework (Python 2.7 for Fig. 1 pipelines).

## Limitations

- Even at 99% identity, none of the variable regions covered by partial 16S sequencing recaptured the diversity represented by the full ~1500 bp gene; the V4 region performed worst.
- The study did not determine how well the 99% identity threshold separates intragenomic vs. inter-genomic sequence variation for all bacterial species.
- Full-length 16S clustering at 99% identity was only shown to give reasonable species relative-abundance estimates for Bacteroides; extrapolation to other taxa is untested.
- Results depend on the specific in-silico priming sub-regions generated upstream (task_001); different primer sets would change the amplicon pools and thus the OTU counts.
