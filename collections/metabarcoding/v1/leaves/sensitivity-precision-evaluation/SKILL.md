# sensitivity-precision-evaluation

> **License: noncommercial** — confirm your use is a permitted (noncommercial) purpose before applying; commercial use requires a separate license (see `metadata.tool_license`). <!-- asb-license-banner -->
## Summary

Benchmark metabarcoding pipelines by classifying occurrences as true or false positives against mock and negative control samples, then computing sensitivity TP/(TP+FN) and precision TP/(TP+FP) across minimum read count cut-offs (0, 10, 40, 60) to compare filtering stringency versus detection power.

## When to use

Use when comparing metabarcoding/denoising pipelines (e.g. VTAM vs DALU vs OBIbaR) on datasets containing mock community and negative control samples, so that false and true occurrences can be labeled and precision/sensitivity quantified.

## When NOT to use

- The dataset lacks mock community or negative control samples, so occurrences cannot be labeled as true or false positives
- The goal is pipeline denoising itself rather than cross-pipeline benchmarking — use VTAM filter, DADA2, or OBITools3 directly instead
- A single pipeline's parameter optimization is needed (use VTAM's optimize command) rather than an evaluation of filtering precision/sensitivity trade-offs

## Inputs

- Trimmed, demultiplexed fastq/fasta files for the bat (357 fecal pellet samples, 16S), fish (35 Zingel asper excrement samples, COI), and shark (63 gut content samples, 12S) datasets
- Raw datasets from Dryad and OSF (e.g. osf.io/ymswg, osf.io/7yf2g, osf.io/wp6u8, osf.io/q69de, osf.io/7pt3x, osf.io/aqrkb)
- Reference databases: COInr COI and RDP Classifier 16S trainsetNo18 formatted for VTAM
- Mock community and negative control sample metadata for labeling true/false occurrences

## Outputs

- out/summary_min_readcount_XX/control_counts.tsv (control-sample true/false positive counts per cut-off)
- Sensitivity TP/(TP+FN) and precision TP/(TP+FP) values per pipeline, dataset, and minimum read count cut-off
- Sensitivity/precision plots generated by scripts/plt_sensitivity_precision.py

## How to apply

Run each pipeline over the same trimmed, demultiplexed fastq/fasta inputs (VTAM filter with per-dataset optimized parameters; DALU via DADA2 denoising plus LULU curation; OBIbaR via OBITools3 obi uniq/grep/clean plus metabaR filters), sweeping the minimum read count cut-off over 0, 10, 40, and 60 to mirror VTAM's suggested cut-offs (10 fish, 40 shark, 60 bat). Classify occurrences as true or false positives against mock and negative control samples using the count_false_occ option of add_filters.pl, producing out/summary_min_readcount_XX/control_counts.tsv. Compute sensitivity as TP/(TP+FN) and precision as TP/(TP+FP) per pipeline and dataset, keeping taxonomic assignment homogeneous by using VTAM's taxassign command for all three pipelines. Plot the results with scripts/plt_sensitivity_precision.py; a correct application reproduces VTAM's higher precision (e.g. precision 1.00 on the five marine fish samples vs 0.66 for OBIbaR and 0.19 for DALU) at comparable sensitivity (0.95–1), and shows DALU/OBIbaR precision rising with the read count cut-off.

## Examples

```
python scripts/plt_sensitivity_precision.py  # after snakemake runs of 02snkfl_analysis_vtam.yml ... 05snkfl_min_readcount.yml produce out/summary_min_readcount_XX/control_counts.tsv
```

## Evaluation signals

- VTAM attains precision 1.00 on the five marine fish samples versus 0.66 (OBIbaR) and 0.19 (DALU) while sensitivity is 0.95–1 for all pipelines
- Precision of DALU and OBIbaR monotonically increases as the minimum read count cut-off rises from 0 to 60
- Sensitivity for all three pipelines stays comparably high (≈0.95–1) across the three datasets and both markers (COI, 16S)
- control_counts.tsv files are produced for every cut-off directory out/summary_min_readcount_XX (0, 10, 40, 60)
- Taxonomic assignment is identical in provenance: all pipelines' ASVs are assigned via VTAM's taxassign command

## Limitations

- Adequate mock communities must exist; commercial mocks are available for bacteria and fungi but metabarcoders studying metazoa or plants must construct their own mock samples
- FilterCodonStop and FilterIndel were skipped for the shark dataset, so the exact VTAM filter set is marker/dataset dependent
- Software versions of DADA2, OBITools, VTAM, and metabaR and dataset accession identifiers were not fully reported in some sections, complicating exact reproduction
